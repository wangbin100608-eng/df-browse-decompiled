## 2. 标注质量（人工审核）

| 指标 | 值 | 证据 |
|---|---|---|
| 独立测试标注总数 | 38 | annotations.jsonl 行数 |
| 审核通过 | 31（81.6%） | human_review=approved |
| 驳回 | 7（18.4%） | human_review=rejected |
| 驳回原因 | 框到空白/UI文字/非目标 | reject_reason 字段 |
| 全部驳回的类别 | CAT止血带（2/2 驳回） | 小图标+贴数字角标，自动框选易框到文字 |
| 重复 bbox | 0 | 本报告 2.6 统计 |
| 训练/测试帧重叠 | 空集 | 本报告第三节 |

**结论**：自动/半自动框选在贴角标的小物品上错误率高（CAT 100% 驳回），需人工复核环节——报告已保留审核结果。

## 3. 特征库质量（item-features.json）

| 指标 | 值 | 影响 |
|---|---|---|
| id 与 item-database 对应 | 1663/1663 完全一致 | ✅ 一一对应 |
| 唯一 phash | 1400 / 1663 | 87 组共 350 件外观相同 |
| 纯普通非武器重复组 | 51 组 | 房卡/藏宝图等物理不可区分 |
| 最大重复组 | 16 件 | 博物馆/旅店系列房卡 |
| hist 非零桶分布 | {1桶:1271, 2:240, 3:97, 4:54, 5:1} | **76.4% 物品直方图退化为单桶**，区分力极弱 |

**结论**：特征库"一一对应但区分力有限"——dHash 同外观上限 + hist 退化，是 dHash 路线失效的数据层根因（印证 accuracy-report L58/L64）。

## 4. 类别平衡

### 4.2 全库普通非武器类

props 795（收集品669/钥匙80/消耗品34/曼德尔砖12）+ protect 98（护甲26/头盔27/胸挂19/背包26）= 893 件，但**仓库无一件参考图片本体**（第一阶段审计 G1），仅 CDN URL。当前训练只覆盖视频中出现的 16 类，893 件中绝大多数无标注。

## 5. 分辨率/亮度/背景质量

## 6. 缺失数据（本阶段确认）

1. 普通非武器类 CDN 参考图片本体（893 件全部缺失，仅 URL）；
2. 每个类别的真实独立标注（低频类仅 2 样本）；
3. 不同对局/不同设备的独立测试帧（当前独立测试仍来自同两个视频）；
4. CAT 止血带的有效框（全部被驳回）；
5. 北极星与 item-database 的映射（classes.json 中 item_id 为空）。

## 7. 质量结论

数据"元数据完备、特征一一对应但区分力弱、真实标注规模小且不平衡、独立测试受素材来源限制"。**任何模型指标都必须放在这个数据规模下解读**（检测器 mAP50 0.51、独立分类 macroF1 0.364 都是数据受限的真实反映，非算法选择错误）。
